# Landing artwork

`kitchen-memory-v1.webp` is original artwork generated with the built-in image-generation tool for the fictional kitchen-table example. It is not a customer photo or testimonial. The decorative image has empty alt text inside an aria-hidden book cover; the adjacent HTML panel explains the example.

Delivery asset: 720 × 960, WebP quality 82, 39,284 bytes. The original PNG remains outside the repository. The application serves the optimized file locally, with a fixed layout and no external image host, runtime image-generation call or image-optimization request. The existing logo and brand assets are unchanged.
