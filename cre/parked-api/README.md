# Parked CRE implementation

These files preserve the former Next API handlers for investigation. They are outside `app/api` and must not be mounted, imported into runtime routes, or used by the evaluation runner. Their historical claims and comments are not guarantees.

Active trigger/callback routes return 410 without inference, storage or chain work. The check route returns an unverified coming-soon state. Testnet verification is parked; reactivation needs a separate decision, security review, proof verification, replay/persistence testing and rollout evidence. See [current runtime operations](../../docs/AI_RUNTIME_AND_OPERATIONS.md) and [the historical CRE assessment](../../docs/CRE_LAYER_ASSESSMENT.md).
